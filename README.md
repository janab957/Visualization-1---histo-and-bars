# Interactive Traffic Accident Visualization

## Overview
An interactive data visualization project that explores traffic accident patterns across different times of the day and weekdays using D3.js.

## Features
- Interactive histogram showing accident counts by time period.
- Weekday comparisons using small multiple charts.
- Linked charts with interactive highlighting and filtering.
- Tooltips displaying accident information.
- Minimum and maximum accident count highlighting.

## Technologies Used
HTML, CSS, JavaScript, D3.js, and CSV.

## How to Run
Open `index.html` in a web browser with an internet connection.

## Purpose
To make traffic accident data easier to explore and understand through interactive visualizations.
